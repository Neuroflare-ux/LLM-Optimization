# AI Optimization

A running record of experiments in getting accurate, useful results from AI,
while catching its assumptions and errors.

## Method
1. Give context, goal, and constraints
2. Ask the AI to flag assumptions and confidence
3. Verify important claims against sources or by running code
4. Log what held up and what didn't

## Structure
- `log/` daily entries
- `principles/` lessons distilled from the logs
- `templates/` reusable prompts and the entry template
- `fields/` field-specific notes (quantum, finance, ...)
